# 嘉立创 EDA 个人元器件库存

这是一个面向嘉立创 EDA 专业版 V3 的个人元器件库存扩展。它帮助你记录手头有哪些元器件、放在哪里、还剩多少，并在设计、备料和采购前检查库存是否够用。

扩展不需要自建服务器或数据库。当前版本为 `0.5.22`，支持简体中文和英文界面。

文中的“BOM”是物料清单，也就是设计中需要使用哪些元器件及其数量的表格；“EDA 模型”是嘉立创 EDA 中可以直接放到原理图上的器件库模型，它和立创商城中的商品不是一回事。

## 能帮你做什么

- 通过立创 C 编号、自定义表单、立创订单文件或包装二维码建立库存。
- 使用分类、搜索、筛选、收藏、最低库存提醒，以及柜、盒、行、列等存放位置管理元器件。
- 在原理图中从库存选择并放置元器件，或定位当前选中器件对应的库存记录。
- 检查当前设计或外部 BOM 的缺料情况，对比两份 BOM，并按 BOM 整批出库或撤销。
- 汇总多个项目的物料需求，生成采购建议并记录采购成本。
- 手动备份和恢复库存；客户端还支持自动备份；需要时可通过 JSON（`.json`）备份文件在浏览器版与客户端之间迁移库存。

## 安装与第一次使用

1. 获取 `jlceda-inventory_v0.5.22.eext`。
2. 打开嘉立创 EDA 专业版 V3，进入“高级 -> 扩展管理器 -> 导入”。
3. 选择扩展包并启用“元器件库存”；需要固定在顶部时，可勾选“显示在顶部菜单”。
4. 从顶部“元器件库存 -> 库存总览”打开主窗口。
5. 先添加一条测试库存，确认保存、搜索和编辑正常。如果使用安装在电脑上的嘉立创 EDA 客户端，建议随后配置自动备份；如果直接在浏览器中使用嘉立创 EDA，建议定期使用“另存库存备份”。

首页、原理图和 PCB 都提供“元器件库存”菜单。原理图额外提供“从库存放置元器件”；原理图和 PCB 都提供“定位选中元器件库存”和“校验当前设计库存”。

## 添加与管理库存

### 库存总览

入口：“元器件库存 -> 库存总览”。

![分类化库存总览，包含搜索、分类、库存状态、可放置模型状态和批量操作](images/inventory-overview-demo.png)

总览用于日常查看和维护库存。你可以按 C 编号、厂家型号、名称、制造商或封装搜索，按分类、库存状态、是否需要补货、是否具备可放置的 EDA 模型等条件筛选，并调整排序、每页数量和显示列。

每条记录可以查看详情、完整编辑、收藏、删除或移动分类；也可以勾选多条记录后批量移动。库存支持最多两级自定义分类，并可分别填写柜、盒、行、列等存放位置。删除分类不会删除元器件，只会把相关记录移到“未分类”。

为元器件设置希望至少保留的数量（最低库存）后，可以筛选需要补货或盘点的记录并导出 CSV。明确填写的数量用于判断是否充足；估算数量会提示再次核对，未知数量会提示盘点实物。

### 按立创 C 编号添加

入口：“元器件库存 -> 按立创 C 编号添加”。

输入 C 编号后，扩展会尝试在嘉立创 EDA 系统器件库中查找可用于原理图放置的模型，并把查到的名称、封装等信息作为建议。你可以逐项采用或保留自己的内容，再填写数量、分类、存放位置、最低库存和备注。

没有找到 EDA 模型时仍可保存和管理库存，但该记录不能直接从库存放置到原理图。扩展不会抓取立创商城网页；需要核对商品时会打开官方商城页面，由你确认信息。

### 添加自定义元器件

入口：“元器件库存 -> 添加自定义元器件”。

适合没有 C 编号或需要自行维护信息的物料。名称必填，C 编号可选；填写有效 C 编号后同样可以查询 EDA 模型。数量可记录为精确、估算或未知，也可以标记为已用完。

填写表单的过程不会直接改变库存。只有点击“保存到库存”，或在发现重复记录后确认合并，才会真正修改库存。

### 扫描包装码入库

入口：“元器件库存 -> 扫描包装码入库”。

扫码枪不是必需设备。你可以使用支持二维码的二维扫码枪，并把它设置为“扫码后像键盘打字一样输入”的 HID 键盘模式；也可以用其他工具读取二维码后，把完整内容粘贴到输入框。扩展不会调用电脑或手机摄像头。

扩展会识别包装码中的 C 编号、厂家型号和数量，先让你核对二维码原文和识别结果，再打开已经填好相关信息的新增页面。扫码或粘贴本身不会直接增加库存，最后仍需确认保存或合并。

### 导入订单文件

入口：“元器件库存 -> 导入订单文件”。

先从立创商城导出订单详情文件，再在扩展中选择一个或多个文件。扩展支持立创订单 `.xls`、`.xlsx`，也兼容规定格式的 CSV 和 JSON；它不能直接读取你的商城账户订单。

导入前可以选择处理已有库存的方式：采购入库时累加数量、用订单数量重置库存，或只新增当前没有的物料。扩展会逐文件显示订单号、物料数量、重复原因和预计新增、合并、跳过结果；只有确认导入后才会写库存。

扩展会检查订单号，并判断所选文件是否与已经导入过的文件相同，以免误重复导入。详细格式见[订单导入格式](https://github.com/bluescola/jlceda-inventory/blob/main/docs/order-import-format.md)。

### 分类、个人库和重复记录

在库存总览的分类管理中，可以手工建立两级分类，也可以从当前工作区的个人库或收藏库导入已有分类。分类导入只新增或合并分类，不会自动移动库存记录。

这里的“个人库”指嘉立创 EDA 自带的个人器件库，不是本扩展的库存列表。具有可用 EDA 模型的库存记录可以复制到个人库；复制成功只代表个人库中已有该器件，不会改变库存数量。

如果新增或编辑的 C 编号、厂家型号等信息与已有记录重复，扩展会并列显示现有记录与待保存记录。只有确认后才会合并，取消则保持原库存不变。

## 在设计中使用库存

### 从库存放置元器件

入口仅位于原理图：“元器件库存 -> 从库存放置元器件”。

扩展会打开库存总览，优先显示有库存且 EDA 模型可用的记录。点击“放置”后，器件会跟随鼠标移动，再由你在原理图画布上点击确定位置。

放置不会自动扣减库存，因为扩展无法可靠判断你最终是否完成了放置。生产领料应使用“按 BOM 整批出库”或手工编辑库存。

### 定位选中元器件库存

入口位于原理图和 PCB：“元器件库存 -> 定位选中元器件库存”。

先在画布中选择一个或多个器件，再执行该命令。库存总览会显示所有匹配记录，并单独列出没有找到库存的器件。这个过程只负责查找和定位，不会修改库存；需要补录时再由你打开新增流程。

### 校验当前设计库存

入口位于原理图和 PCB：“元器件库存 -> 校验当前设计库存”。

输入计划生产的板数后，扩展会读取当前设计中的器件需求，汇总总用量，并标记库存充足、不足、没有库存记录、数量需要核对或无法匹配到库存的项目。

![库存检查结果，按板数汇总需求并标记充足、不足、需要核对、没有库存记录和无法匹配库存](images/stock-check-demo.png)

检查结果可以导出缺料 CSV。这个功能只会查看和计算数据，不会扣减库存，也不会自动生成订单；当前设计无法读取时，可以改用外部 BOM 检查。

## BOM、备料与生产

外部 BOM 文件支持 CSV、TXT、XLS 和 XLSX。扩展会先识别文件中的工作表和标题行，再让你指定哪一列表示 C 编号、数量、位号（如 R1、C3）、封装和不装配，避免按错列处理物料。

![两份 BOM 的工作表、标题行、每列用途设置和原始内容预览](images/bom-mapping-demo.png)

### 校验外部 BOM 库存

入口：“元器件库存 -> 校验外部 BOM 库存”。

选择一份 BOM，确认每一列的用途并输入板数后，可以查看每种物料的总需求、当前库存和缺口，并导出缺料 CSV。这个功能只会查看和计算数据，不会修改库存。

### 对比 BOM 版本

入口：“元器件库存 -> 对比 BOM 版本”。

一次选择两份 BOM，分别作为原版本和新版本。扩展会列出新增、移除、数量变化，以及 C 编号或厂家型号变化，并把无法识别的内容单独列出供你检查。结果可以筛选和导出 CSV，不会修改库存。

### 按 BOM 整批出库

入口：“元器件库存 -> 按 BOM 整批出库”。

出库就是按本次生产用量扣减库存。选择一份 BOM、确认每一列的用途并输入板数后，扩展会先预览每项物料扣减前后的数量，以及所有导致无法出库的问题。只有每种物料都能匹配、库存数量明确且足够，并且你再次确认后，才会一次性扣减整批库存。

整批出库遵循“全部成功或全部不处理”：只要有一项不满足条件，一条库存也不会修改。相同物料和数量的需求再次出库时，扩展会提示可能重复；确实属于下一批生产时，可由你明确确认。

### BOM 出库与撤销记录

入口：“元器件库存 -> BOM 出库与撤销记录”。

这里显示 BOM 整批出库以及对应的撤销记录，不是所有库存编辑和订单入库的完整历史。尚未撤销的批次可以整批撤销；撤销后会恢复原批次扣减的数量，并新增一条对应的撤销记录。已经撤销的批次不能再次撤销。

## 项目需求与采购

### 设计需求记录和采购建议

入口：“元器件库存 -> 项目需求与采购”。“捕获当前设计”需要在已打开的原理图或 PCB 中执行。

扩展可以把当前设计当时的物料需求保存成一份“设计需求记录”。你可以为每份记录设置生产板数；再次从设计更新记录时，扩展会先显示新旧差异。多份记录会合并计算总需求、当前库存和建议采购数量，采购建议可以导出 CSV。

当前不能从外部 BOM 创建这种需求记录。同一块实体电路板如果同时保存原理图和 PCB 两份记录，会被当成两个独立需求重复累计，因此只应保留其中一份。

### 采购记录

采购记录用于手工登记采购数量、平台、订单号、日期、币种和单价，并按币种汇总成本。登记采购记录不会自动增加库存，货物到达后仍需通过新增、订单导入或包装码入库。

单价按货币的最小单位填写，例如人民币按“分”填写。币种为 `CNY` 时，输入 `125` 表示 1.25 元。

### 替代料关系

入口：“元器件库存 -> 管理替代料关系”。

先选择原本打算使用的物料，再人工选择并确认哪些物料可以替代它。输入的需求数量只用于把库存更合适的候选排在前面；替代关系不会自动参与 BOM 匹配、库存检查、扣减或出库，删除关系也不会改变任何库存数量。

## 备份、迁移与恢复

### 数据保存和跨端迁移

库存保存在嘉立创 EDA 为扩展提供的数据空间中，不需要额外数据库。浏览器中打开的嘉立创 EDA 与安装在电脑上的嘉立创 EDA 客户端会各自保存一份库存，两边不会自动同步，也不能当作同一份云端库存使用。

要把库存从浏览器版转到客户端，或从客户端转回浏览器版，请先在当前使用的一侧另存 JSON 备份，再在另一侧使用“恢复库存备份”，用备份整体替换那里的现有库存。

### 另存库存备份

入口：“元器件库存 -> 另存库存备份”。

通过系统保存对话框导出一份完整、可迁移的 JSON 备份文件。另存操作只写备份文件，不会修改当前库存。浏览器版和客户端都可以使用。

### 自动备份设置

入口：“元器件库存 -> 自动备份设置”。

自动备份只在安装于电脑上的嘉立创 EDA 客户端中可用，并需要在扩展管理器中开启“允许外部交互”权限，让扩展能够选择目录并写入备份文件。首次设置时选择一个目录，扩展会创建并持续更新 `jlceda-inventory-latest.json`。它只保留最新备份，不保留多个历史版本。

当前库存保存成功后才会刷新自动备份。备份失败会给出提示，但不会撤销已经成功的库存修改。

### 恢复库存备份

入口：“元器件库存 -> 恢复库存备份”。

可以选择外部 JSON 备份文件，或在可用时选择上一次恢复前自动保留的副本。扩展会先检查文件是否有效，并列出其中包含多少库存记录、分类和历史记录，只有再次确认后才会写入。

恢复会用备份中的全部内容替换现有数据，不会只合并其中几条。确认后，当前库存、分类、订单导入记录、BOM 出库与撤销记录、项目需求、采购记录和替代料关系都会被替换，操作前应先另存当前库存。

## 诊断与版本信息

- “查看诊断日志”用于在扩展内查看最近操作的状态和错误类别。
- “导出诊断日志”会保存诊断 JSON，适合在反馈问题时提供给维护者；不会修改库存。
- “关于库存扩展”显示当前版本和基本信息。

## 支持的文件和限制

| 操作 | 支持的文件 | 数量与大小限制 |
| --- | --- | --- |
| 订单导入 | 立创订单 XLS/XLSX、规定格式的 CSV/JSON | 一次最多 100 个文件；每个不超过 10 MB，合计不超过 50 MB |
| BOM 校验或整批出库 | CSV、TXT、XLS、XLSX | 每次 1 个文件；不超过 10 MB |
| BOM 版本对比 | CSV、TXT、XLS、XLSX | 必须同时选择 2 个文件；每个不超过 10 MB |
| 包装二维码 | 扫码枪输入或粘贴的文本 | 最长 4,096 个字符；必须包含有效 C 编号，数量必须为正整数 |
| 库存备份与恢复 | 本扩展导出的 JSON | 最大 10 MB、最多 10,000 条库存；恢复会替换全部现有数据 |

一个 Excel 文件最多读取 32 个工作表，每个工作表最多 128 列和 10,000 行数据。超过限制的文件会在处理前被拒绝。

## 常见问题

### 扫描包装码一定要买扫码枪吗？

不需要。支持二维码的二维扫码枪可以提高连续入库效率，也可以直接粘贴二维码原文。扩展本身不使用摄像头。

### 有 C 编号为什么不能从库存放置？

C 编号代表商城商品身份，放置还需要嘉立创 EDA 可用的器件模型。没有模型的记录仍可保存、搜索、统计和参与缺料检查。

### 放置元器件或检查库存会自动扣库存吗？

不会。只有明确的库存保存、编辑、删除、合并、订单导入、BOM 整批出库、撤销，或使用备份替换全部数据时，才会修改库存。

### 为什么浏览器版里看不到客户端保存的库存？

浏览器版和客户端各自保存库存，不会自动同步。请通过“另存库存备份”和“恢复库存备份”迁移 JSON。
